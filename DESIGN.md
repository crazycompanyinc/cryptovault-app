## Overview

CryptoVault es la plataforma de trading cripto con IA que combina la elegancia institucional de Stripe con la energía de Bitcoin. El diseño es oscuro, premium y técnico: fondos GitHub-dark (#0d1117) con acentos Bitcoin naranja (#f7931a) que brillan como el oro digital. La tipografía Source Sans 3 en weight 300 crea headlines etéreos y lujosos — la confianza de un banco suizo con la velocidad de un exchange de primer nivel.

Cada sombra tiene un tinte azul sutil (rgba 50,50,93) como Stripe. Los datos numéricos usan Source Code Pro con tabular nums. Los bordes son susurros. La experiencia transmite seguridad, sofisticación y poder financiero.

## Colors

- **Primary (#0d1117):** GitHub dark — el fondo estándar de los desarrolladores crypto.
- **Accent (#f7931a):** Bitcoin Orange — el naranja icónico, usado con moderación estratégica.
- **Accent Secondary (#627eea):** Ethereum Blue — para elementos secundarios de marca.
- **Success (#00d395):** Verde trading — ganancias, balances positivos.
- **Danger (#ff4757):** Rojo trading — pérdidas, alertas.
- **Text Primary (#f0f6fc):** Blanco GitHub — máxima legibilidad.
- **Text Secondary (#8b949e):** Gris GitHub — texto de apoyo.
- **Shadows:** Blue-tinted (rgba 50,50,93) como Stripe — profundidad con atmósfera.

## Typography

- **Source Sans 3** — weight 300 para headlines (etéreo, premium), 400 para UI, 600 para CTAs.
- **Source Code Pro** — weight 500 para precios, datos numéricos, con font-feature "tnum".
- **Headlines:** Weight 300, letter-spacing negativo progresivo (-0.03em h1, -0.02em h2).
- **Body:** Weight 300, line-height 1.6 — lectura cómoda y elegante.
- **Principio:** La ligereza del weight 300 ES la marca. No usar bold (700) excepto en botones CTA.

## Layout

- **Max-width:** 1100px centrado (más estrecho que FitPulse para sensación premium)
- **Secciones:** Full-width con padding lateral responsive
- **Grid de features:** 4 columnas desktop → 2 tablet → 1 mobile
- **Hero:** Centrado, con ticker de precios flotante y glow naranja sutil
- **Dark sections:** Alternar entre #0d1117 y #161b22 para ritmo visual
- **Spacing vertical:** 80px desktop, 48px mobile

## Secciones

1. **Hero:** "Trading Cripto con IA de Grado Institucional" — headline etéreo weight 300, subtítulo, CTA primario (gradient naranja→dorado), precio BTC/ETH en vivo (simulado)
2. **Ticker Bar:** Barra con precios de cripto principales (BTC, ETH, SOL, ADA) con cambios %
3. **Features:** 4 cards — Trading IA, Seguridad, Staking, Swap — con iconos geométricos
4. **Mercados:** Tabla de mercados con precios, cambio 24h, sparkline (SVG mini-chart)
5. **Seguridad:** Sección con iconos de escudo, cold storage, 2FA, insurance
6. **Planes:** 3 tiers (Basic/Pro/Elite) — Basic gratis como lead magnet
7. **Stats:** Métricas grandes — $2B+ volumen, 500K+ usuarios, 99.9% uptime
8. **FAQ:** 5 preguntas con accordion
9. **CTA Final:** "Empieza a invertir hoy" con gradient naranja
10. **Footer:** Links, social, legal, disclaimer

- **Gradient Gold CTAs:** Botones con gradiente naranja→dorado (como el oro de Bitcoin)
- **Blue-tinted shadows:** Sombras con tinte azul como Stripe
